# How to Deploy a Website on GitHub Pages : ---------------> {}{}{} <----------------->

### Step 1: Create a New Repository

1. Go to GitHub and click **New Repository**.
2. Enter the **Repository Name**.
3. Add a short **Description** of your project.
4. Choose the repository visibility:

   * **Public** – anyone can view the repository.
   * **Private** – only authorized users can access it.
5. Select **Add a README file**. It is useful for documenting your project.
6. Click **Create Repository**.

### Step 2: Upload Project Files

1. Open your newly created repository.
2. Upload all required project files, such as:

   * `index.html`
   * `style.css`
   * `script.js`
   * Images and other assets
3. Update the **README.md** file if required.
4. After making any changes, always **Commit Changes** to save them to the repository.

### Step 3: Configure Repository Settings

1. Go to **Settings** of the repository.
2. Check the **Repository Name** and change it if necessary.
3. Make sure the default branch is set to **main**.

### Step 4: Configure GitHub Pages

1. In **Settings**, go to **Pages**.
2. Under **Build and deployment**, select:

   * **Source:** `GitHub Actions`
3. Select the **Static HTML** workflow.
4. Click **Configure**.

### Step 5: Create and Commit the Workflow

1. GitHub will automatically open the workflow configuration page.
2. A `.yml` file will be created.
3. You can rename the `.yml` file if required.
4. Click **Commit Changes**.

### Step 6: Check the Deployment Status

1. Go to the **Actions** tab of your repository.
2. Find the deployment workflow.
3. Check the status:

   * 🟡 **Yellow Dot:** Deployment is still in progress. Wait until it finishes.
   * 🟢 **Green Tick:** Deployment completed successfully.
   * 🔴 **Red Mark:** Deployment failed; check the workflow logs for errors.

### Step 7: Visit Your Website

1. Return to **Settings → Pages**.
2. Under the deployment section, click **Visit Site**.
3. Verify that your website is working correctly.
4. Copy the website URL and share it with others.

### Deployment Complete! 🎉

Your static website is now deployed and accessible through **GitHub Pages**.
